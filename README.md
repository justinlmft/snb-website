# snb-website — WEBSITE ONLY

Live page content for the **Stuck Not Broken website** (stucknotbroken.com — the Circle pages).

**This is not the app.** The app lives in `stuck-not-broken`.

**Do not hand-edit page files here.** Text files (loader, CSS, partials) are published
automatically from `snb-business` → `Projects/Web Designer/SNB-Web-Live/public/` by the
`publish-website` function; hand edits to them are overwritten on the next publish.

**Images live here.** Everything under `img/` is the only copy the website uses. New website
images are committed straight to `img/` in this repo. A publish never removes anything under `img/`.

Served at https://justinlmft.github.io/snb-website/
